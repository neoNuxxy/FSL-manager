About FSL Manager

A platform created to simplify the management of school internships.

The progect

What's FSL Manager

FSL Manager is a digital platform developed to manage the FSL internship program. It allows students and teachers to track every stage of the training process—from hours completed to required documents—in a simple and transparent way.

For the students

Track hours, keep track of documents, and follow the progress of your internship in real time.

For teachers

Manage placements, check attendance, and update student data from a single dashboard.

Total transparency

Every action is recorded. Documents, hours, and deadlines are always visible to the relevant personnel.

Tecnology

How it's built

FSL Manager is developed with standard web technologies—HTML, CSS, and pure JavaScript—with no external dependencies. Lightweight, fast, and accessible from any device.

🌐

Web Based

Accessible from a browser without installation. Works on desktop and mobile.

📁

Data on JSON

The data is saved in JSON format, which is easy to export and read.

🔒

Separate roles

Students and teachers have separate access — each sees only what they need.

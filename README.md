# FSL-manager 1.0 (RELEASE)
---------------------------------
## Description
FSL Manager is a web-based system for the comprehensive management of students' FSL (School-to-Work Training) programs. The system was born from the need to digitize, centralize, and simplify the entire school internship management process, from registering participating companies to finalizing the hours worked. The project is built entirely using standard web technologies, with no dependencies on external frameworks, ensuring maximum portability and ease of deployment. The interface consists of multiple HTML pages and JavaScript scripts. Data persistence is ensured by JSON exports downloaded from the browser, making the system completely autonomous and usable without an internet connection.

----------------------------
## Objectives
• Simplify administrative management for the school coordinator  
• Allow students to independently record daily attendance  
• View each student's hours by manually entering their hours  
• Export internship data for external processing  
• Create a solid and scalable foundation for future integration with a relational database
